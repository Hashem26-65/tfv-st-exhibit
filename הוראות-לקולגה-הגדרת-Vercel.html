הזרימה מכאן והלאה

מהרגע הזה, כל push ל-GitHub יוצר אוטומטית פריסה חדשה ב-Vercel:

Claude makes a change in the code
↓
git add . · git commit -m "..." · git push
↓
Vercel auto-builds (~30s)
↓
New URL appears in Vercel Dashboard
↓
You send URL to maintainer for mobile review
↓
If approved → maintainer ports to live site manually

כל branch מקבל URL נפרד. לבדוק שתי גרסאות במקביל:
git checkout -b experiment ואז git push -u origin experiment.

כללים שלא ניתנים למשא-ומתן

  • אין סיסמאות / טוקנים / גישה לאתר התודה להשם החי. אם ה-Claude שלך טוען שצריך — זו טעות. התשובה הנכונה תמיד: "אבנה בחשבונות שלי ואשתף URL פריוויו."
  • אתה לא דוחף לאתר החי. הבעלים עושה את זה ידנית אחרי בדיקה.
  • סטטי בלבד. HTML / CSS / JS. אין צורך ב-Node, npm, או build step.
  • אם משהו מרגיש לא בסדר — עצור ושאל את הבעלים. אל תמציא, אל תעקוף.

בעיות נפוצות וטיפול

בעיהפתרון
git push נכשל עם 403 Token חסר. צור Personal Access Token ב-GitHub עם הרשאת repo, השתמש בו כסיסמה ב-push הבא.
Vercel מציג 404 ב-URL הראשי שכחת לקבוע Root Directory בשלב 7.3. Project → Settings → General → Root Directory = reference-exhibits/sum-of-thousands. אחרי שמירה → Redeploy.
העברית לא מוצגת נכון פתח index.html, ודא שיש <html lang="he" dir="rtl"> ו-UTF-8.
הפונטים לא נטענים הקוד מושך מ-Google Fonts. ודא חיבור אינטרנט. בגרסה הסופית הבעלים יעבור ל-bundled fonts.
ה-Claude שלך מבקש להוסיף npm packages מותר רק לכלי פיתוח. הקבצים הסופיים חייבים להישאר HTML/CSS/JS סטטיים.
