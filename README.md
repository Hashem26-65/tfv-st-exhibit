# Sum of Thousands · סכומי אלפים — TFV Exhibit

תערוכה אינטראקטיבית (דף יחיד, RTL עברית + English) המציגה את מערכת
**סכומי האלפים** בפסוק הראשון בתורה — עם קריינות מסונכרנת, אנימציות,
כתוביות, ופס-זמן נגרר.

An interactive single-page exhibit on the **Sum of Thousands** system in
Genesis 1:1, with synchronized narration, animations, captions, and a
draggable timeline.

## הרצה מקומית · Run locally

זהו דף סטטי — אין צורך ב-build. הריצו שרת מקומי מתוך התיקייה:

```bash
python -m http.server 8731
# ואז פתחו http://127.0.0.1:8731/index.html
```

(נדרש שרת — פתיחה ישירה כ-`file://` עלולה לחסום טעינת אודיו.)

## מבנה · Structure

```
index.html                      — הדף הראשי
assets/
  styles.css                    — עיצוב (פלטה כהה/בורדו/זהב)
  cues.js                       — נתונים: ערכי המילים, מספרים מאומתים,
                                  עיתוי אנימציות (he/en), כתוביות (he/en)
  exhibit.js                    — מנוע: ניגון אודיו, סנכרון cue, אנימציות,
                                  כתוביות, פס-זמן, בורר שפה, הגדרות
  logo.png / logo-full.png      — לוגו TFV
אודיו מצגת סכומי אלפים/         — קריינות עברית (5 חלקים)
אודיו אנגלית/                   — English narration (5 parts)
```

## תכונות · Features

- 5 אקטים מתנגנים ברצף עם אנימציות שנוחתות בדיוק על הקריינות
- בורר שפה (עברית / English) — מחליף אודיו, טקסט, כתוביות ועיתוי
- כתוביות (CC) מסונכרנות, פס-זמן נגרר, בקרת מהירות, השהיה
- כל המספרים מאומתים ב-BigInt (∏ ערכי המילים, ×82, ×82²,
  סכום קבוצות האלפים = 2701, סכום הספרות = 82)
