# משחקי הפסוק הראשון · TFV Games

אוסף משחקים אינטראקטיביים ללימוד הגימטריה של הפסוק הראשון בתורה
(בראשית א׳:א׳). אתר סטטי לחלוטין — **ללא שלב build, ללא backend, ללא
dependencies להתקנה** — מוכן להעלאה ל-Vercel או לשילוב ישיר באתר.

> חבילה זו הוכנה לבדיקת מנהלי האתר לקראת שילוב ב-thefirstverse.com.

---

## מה כלול

| קובץ | תיאור |
|---|---|
| `index.html` | דף הבית של המשחקים (Hub) — מקשר לכל המשחקים |
| `memory.html` | **זיכרון גימטרי** — גרסה כהה |
| `memory-cream.html` | **זיכרון גימטרי** — גרסה מלכותית (כחול נייבי + לוגו) |
| `balloons / catch / defense / gematria-range / helicopter / match-pairs / quiz-blitz / snake / sort / torah-race / tower / verse-builder / whack` | 13 משחקוני גימטריה נוספים |
| `ark-defense.html` | **הגנת התיבה** — Tower Defense: מגדלים, פצצות, טילים והשתלטות על חיות, 15 גלים |
| `matrix-games.html` | **משחקי המטריקס** — שחמט, שש־בש ודמקה בעיצוב ניאון (`?g=chess` / `?g=backgammon` / `?g=draughts`): נגד המחשב ב־4 רמות (מנוע ב־Web Worker), שניים על מסך אחד, או אונליין דרך MQTT ציבורי — לובי עם הזמנות או קוד חדר (`&room=ABCD`). הכלים והלוחות ב־`assets/matrix/` |
| `assets/` | לוגואים ונכסים (כולל `tfv-logo.png`) |

### תכונות המשחק הראשי (זיכרון גימטרי)
- **שלבים** — 8 שלבים; שלושת הראשונים ללא זמן, ואז טיימר שמתקצר ככל שמתקדמים, ויותר מילים.
- **שמירת התקדמות** — נשמרת ב-`localStorage`, שורדת יציאה/סגירת טאב (כפתור "המשך").
- **מוזיקת רקע** — נוצרת בזמן אמת (Web Audio), 3 מנגינות + השתקה, דרך כפתור ⚙️ הגדרות.
- **פריסה ללא גלילה** — הלוח מתאים את גודלו אוטומטית לכל מסך (מחשב/לפטופ/מובייל), בלי גלילה.

## הרצה מקומית

אתר סטטי — מספיק שרת קבצים פשוט מתוך התיקייה:

```bash
python -m http.server 8080
# פתח http://127.0.0.1:8080/index.html
```

(פתיחה ישירה כ-`file://` עלולה לחסום טעינת אודיו — מומלץ דרך שרת.)

## העלאה ל-Vercel

הפרויקט כולל `vercel.json` (cleanUrls, ללא trailing-slash, caching לנכסים).

```bash
npm i -g vercel
vercel --prod
```

או דרך GitHub: דחיפת הריפו → vercel.com → **Add New → Project → Import** →
deploy אוטומטי בכל push.

## שילוב באתר (להנחיית מנהלי האתר)

האתר **נייד לחלוטין** — כל הנתיבים יחסיים (`assets/...`, `*.html`), כך שהוא
עובד תחת כל נתיב בסיס. שתי דרכים לשילוב ב-thefirstverse.com:

1. **תת-תיקייה** — להעתיק את תוכן הריפו לתיקייה `games/` בריפו של האתר.
   הכול יעבוד מיד תחת `thefirstverse.com/games/` (למשל `…/games/memory-cream`).
2. **פרויקט נפרד + Rewrite** — להשאיר כפרויקט Vercel נפרד ולהפנות אליו נתיב
   מהאתר הראשי באמצעות rewrite/proxy.

### נקודות לתשומת לב למנהלי האתר
- **אין backend ואין מסד נתונים.** כל הנתונים נשמרים מקומית בדפדפן ב-`localStorage`
  (מפתחות: `tfv_memory_save_v1`, `tfv_memory_music_v1`, וזהים בגרסת ה-cream עם
  הסיומת `_cream_`). אין מעקב, אין cookies.
- **תלות חיצונית יחידה:** גופנים מ-Google Fonts
  (`fonts.googleapis.com` / `fonts.gstatic.com`). אם נדרשת עצמאות מלאה — אפשר
  לארח את הגופנים מקומית.
- **נכסים:** הלוגו והתמונות מקומיים תחת `assets/` (אין hotlinking).
- **דפדפנים:** עובד בכל דפדפן מודרני (Chrome / Safari / Edge / Firefox), כולל מובייל ומגע.
