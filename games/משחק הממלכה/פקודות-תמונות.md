# פקודות ליצירת תמונות הבניינים — משחק הממלכה

מחוללים מומלצים: ChatGPT (DALL·E) או Nano Banana (Gemini Image).

## איך עובדים עם זה
1. מעתיקים את **"כותרת הסגנון"** הקבועה (STYLE BASE) — היא נשארת זהה לכל בניין.
2. מוסיפים אחריה את שורת הבניין הספציפי.
3. שומרים כל תמונה בשם האנגלי שכתוב (למשל `house.png`) בתיקייה `images/`.
4. **חשוב לאחידות:** לבקש בכל פעם רקע שקוף (transparent PNG), אותה זווית, אותו גודל.

> טיפ: אם אפשר, צרו את כל 16 הבניינים **בבת אחת באותה שיחה** וגם בקשו "same art style and scale as the previous images" — כך הם יֵצאו אחידים.

## כותרת הסגנון (STYLE BASE) — להדביק לפני כל בניין

```
Isometric 2.5D game building asset, cute clean cartoon low-poly style like SimCity 3000.
45-degree top-down isometric view, soft lighting from the top-left, gentle ambient-occlusion
shadow under the building, vibrant friendly colors, smooth shading, no text, no people,
single building centered on a fully transparent background (PNG with alpha), 1024x1024,
consistent scale so it tiles next to other buildings of the same set.
Building:
```
